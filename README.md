## ⚡ QUICK LAUNCH COMMANDS

### 1️⃣ Launch Frontend (React 18 + Vite)

```bash
npm install
npm run dev
```
👉 *App URL: `http://localhost:5173`*

### 2️⃣ Launch Backend Microservice (Python FastAPI)

```bash
cd backend
pip install -r requirements.txt
python main.py
```
👉 *API Docs: `http://localhost:8000/docs`*
